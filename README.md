# 2Dplay · 2D 横版闯关原型

一个手感优先的 2D 横版闯关游戏原型。一关 20 屏，约 2~3 分钟，含教学段、难度区与两阶段 Boss。

用 **Unity 6.3 LTS**（Universal 2D / URP）+ 新输入系统制作。

---

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `空格` | 跳跃（长按跳更高；空中再按一次是二段跳） |
| `左 Shift` | 冲刺（**途中无敌，可以直接穿过敌人**） |
| `鼠标左键 / Enter` | 近战挥砍 |
| `C` | 远程弹道（有弹药上限，打空了会慢慢回复） |
| `E` | **弹刀** —— 在被打到前的一瞬间按下，把攻击弹开 |
| `R` | 回到最近的检查点 |
| `ESC` | 暂停 / 操作说明 |

---

## 特色

- **手感优先的移动**：土狼时间、跳跃缓冲、可变跳跃高度、二段跳
- **冲刺无敌帧**：穿过敌人的同时不被撞
- **弹刀**：冲锋兵会变红预警，那一瞬间按 `E` 能把它弹飞并反击 —— 挡下冲锋时僵直是普通弹刀的 **2.4 倍**，还能补一发远程弹药
- **三档难度**：玩家血量、敌人血量/速度/伤害、尖刺伤害、**远程备弹量**、Boss 强度全都跟着变
- **5 个成就**：含"不杀任何杂兵通关"和"一命通关"
- **两阶段 Boss**：跳砸落地产生向两侧扩散的冲击波，二阶段会召唤小兵
- **手感细节**：顿帧、镜头震动、命中火花、受击闪烁、死亡慢动作

## 怎么跑起来

1. 装 **Unity 6.3 LTS**（`6000.3.x`）
2. 克隆本仓库
3. Unity Hub → Add → 选这个目录，等它下载完 Packages
4. 打开 `Assets/Scenes/SampleScene.unity` → Play

> 仓库里**没有** Unity 的任何二进制文件，Packages 由 Unity 自己下载。原因见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 一键生成关卡

菜单 **`Tools → 2D 平台跳跃 → 生成教学关（一键）`** —— 整个 20 屏关卡由脚本生成，
改数值后重新生成即可。

### 一键打包

菜单 **`Tools → 2D 平台跳跃 → 打包前自检 / 打包 Windows / 打包 WebGL`**。

## 关于素材

**目前全部是占位素材**：像素画和音效都由 `build/` 下的 Python 脚本程序生成。

- `make_tiles.py` — 地形 Tile
- `make_characters.py` — 主角 / 敌人 / Boss 精灵 + 游戏图标
- `make_audio.py` — 16 个 8-bit 音效 + 1 段循环 BGM

**换正式素材时保持文件名不变直接替换，代码一行都不用改。**
